# RepoLens

Multi-language, multi-repository **open-source license disclosure** for a configured
owner: discover every repo, inventory dependencies in any language, flag commercial-use
risks and unfindable licenses, resolve them with anchored evidence under human approval,
and assemble a deduplicated report.

RepoLens **orchestrates** mature tools (Syft, ScanCode, registry/GitHub/deps.dev APIs,
native mobile tools) — it does not reimplement scanners.

See **[docs/roadmap](docs/roadmap/rpl_README.md)** for requirements, decisions,
architecture, the mandatory security guardrails, and the build roadmap.
